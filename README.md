One front page that sums up the day's world news: three illustrated lead stories, ten more, a dotted world map, 22 more in brief, a date check that names the older stories left out, and the day's numbers (Dow 49,595, S&P 7,237, Nasdaq 24,090).

## Run it

```sh
python3 main.py
```

The program copies the pre-rendered `entry.png` (1024×1024, deterministic, byte-identical on every run) to `$MAKEFUN_OUTPUT_DIR/entry.png`. To re-render the page from its data, run `python3 render.py` (needs Pillow and the DejaVu fonts; hero art in `illu/` is optional — drawn scenes are used as fallback).
